# NEON SNAKE — общий рейтинг на Netlify

Игра и общий серверный рейтинг размещаются в одном Netlify-проекте. Все посетители одной ссылки видят одну таблицу, независимо от браузера и устройства. Результаты хранятся в **Netlify Blobs**, не в localStorage.

## Деплой

1. Подключите этот GitHub-репозиторий к Netlify, ветка `main`.
2. Base directory — пусто, Publish directory — `dist`, Build command — `npm test`. Настройки уже записаны в `netlify.toml`.
3. Запустите новый production deploy. Netlify установит `@netlify/blobs` и опубликует функцию `api` с маршрутом `/api/*`.
4. В списке Functions должна появиться `api`. Откройте сайт и сыграйте завершённую партию с ненулевым счётом. Откройте эту же ссылку в другом браузере — результат должен быть виден и там.

**Нельзя загружать только dist перетаскиванием:** это публикует только HTML, без серверных функций. Используйте GitHub-деплой всего репозитория. Секреты, SQL-база и отдельный Render-сервер для Netlify-версии не нужны: доступ функции к Blobs предоставляется платформой.

Хранилище `neon-snake-global-v1` относится к сайту и переживает новые деплои. Разные Netlify-проекты имеют отдельные хранилища. Preview-деплои того же сайта используют этот же store, поэтому результаты тестовых партий могут попасть в рейтинг.

## Поведение

- Публичный топ-50 доступен даже без профиля; отображается собственное место, если профиль есть.
- Один лучший результат на профиль и режим. Четыре таблицы: классика/приключение × стены/сквозь края. Zen вне рейтинга.
- Верхняя панель показывает мировой рекорд текущего режима. При недоступном сервере вместо локального рекорда отображается тире.
- Профиль гостевой: cookie связывает браузер с серверной записью. Другой браузер создаёт другого гостя, но видит **ту же общую таблицу**. Переноса личности между устройствами без регистрации нет.
- Ник и очки публичны. Ники не уникальны, их можно менять.
- После завершения партия отправляется автоматически; повторная отправка идемпотентна. Временно неотправленную последнюю партию можно отправить кнопкой, пока вкладка открыта.
- Перезапуск или выход в меню не публикует незавершённую партию. Для рейтинга API должен быть доступен при старте.
- В браузере остаются настройки и косметический прогресс. Локальные очки не импортируются в мировой рейтинг.

## Надёжность и ограничения

Записи читаются с strong consistency. Изменения профиля, партии и рекорда записываются одним условным обновлением по ETag с повтором при конфликте. Параллельные вкладки не должны затирать лучший результат. Незавершённые/завершённые сессии старше суток очищаются при следующем старте; максимум 30 стартов в минуту и 200 за сутки на профиль.

Проверяются владелец партии, режим, диапазоны очков и минимальная длительность. Это **базовая проверка, не турнирный античит**: браузерную игру можно модифицировать. Чтение рейтинга сканирует гостевые профили постранично с ограниченным параллелизмом; для большой аудитории нужен индекс рейтинга/SQL-база. Лимиты использования и стоимость зависят от аккаунта Netlify.

Старые SQLite-результаты автоматически в Blobs не переносятся. Гостевые профили и рекорды остаются в хранилище до удаления администратором; для обслуживания используйте интерфейс Blobs в Netlify.

## Проверка локально

Node.js 24:

```sh
npm install
npm test
```

Тесты проверяют двух независимых посетителей, одинаковую таблицу, холодные запуски функции, параллельные записи, повторы, разделение режимов и механику игры. Облачный store в unit-тестах заменён моделью API с ETag; настоящий production-деплой нужно проверить отдельно.

Для запуска с Netlify Functions используйте Netlify CLI, привязанный к проекту:

```sh
npx netlify dev
```

Netlify Dev использует отдельное локальное хранилище — это среда разработки, не публичный рейтинг.

Сохраняется альтернативный `npm start` / Docker / Render: он запускает старый сервер Node.js + SQLite с отдельной базой. Он не подключён к рейтингу Blobs. В Netlify используется `netlify/functions/api.mjs`, а не `server.mjs`.

## Структура

- `dist/` — клиентская игра.
- `netlify/functions/api.mjs` — облачная функция.
- `lib/cloud-api.mjs` — рейтинг и проверки.
- `test/cloud.test.mjs` — проверки общего рейтинга.
- `netlify.toml` — настройки деплоя.
- `server.mjs`, Dockerfile, render.yaml — альтернативный SQLite-хостинг.

Документация: https://docs.netlify.com/build/data-and-storage/netlify-blobs/ и https://docs.netlify.com/build/functions/configuration/
